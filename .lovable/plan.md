

# Fix Layout Width + Add Branded Export Report

## Part 1: Widen the Results Page

The current container uses `max-w-6xl` (72rem / 1152px), leaving a lot of unused space on wider screens. We'll widen it to use more available space.

### File: `src/pages/ScanResults.tsx`
- Change `container max-w-6xl` to `container max-w-[1600px]` on the main wrapper div (line 66)
- This gives the 2-column community cards much more room, preventing the header text/button wrapping issue entirely

## Part 2: Add Branded PDF-style Export

Add a "Download Report" button that generates a clean, AudienceScan-branded HTML report and opens it in a new tab for printing/saving as PDF. This avoids needing a PDF library -- the browser's native Print dialog handles it perfectly.

### New File: `src/lib/report-export.ts`
A utility that builds a self-contained HTML document string with:
- **Header**: AudienceScan logo, scan name, date, chain, wallet count
- **Summary Stats**: Wallets processed, tokens found, enriched, social signals -- styled as a clean stat row
- **Communities Section**: Platform-by-platform tables (X handles, Telegram channels, Reddit, Discord) with token name, handle, and market cap
- **News Section**: Top news articles with source, title, date
- **Websites Section**: Project websites list
- **Footer**: "Generated by AudienceScan" with date

Styling:
- Clean print-friendly CSS with `@media print` rules
- AudienceScan orange (#F97316) accent color for headers and dividers
- Professional typography, no background textures
- Page break hints between sections

### File: `src/pages/ScanResults.tsx`
- Add a "Download Report" button next to "View Full Network" in the header area
- The button calls the report generator, opens the HTML in a new window, and triggers print

### File: `src/components/scan-results/ExportCenterTab.tsx`
- Add a prominent "Download Branded Report" card at the top of the Export tab with a description explaining it generates a print-ready PDF report

### Data Flow
The report generator receives the `Scan` object and `ScanResultsResponse` and formats everything client-side. No new API calls needed -- it uses the same data already loaded on the page.
